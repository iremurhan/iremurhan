# Beyza İrem Urhan

I work on vision–language models, mostly fine-tuning CLIP for image–text retrieval. MSc in Computer Engineering, Boğaziçi University.

**Research interests:** multimodal representation learning, vision–language models, contrastive learning, cross-modal retrieval, parameter-efficient fine-tuning, foundation model adaptation.

## Projects

- [clip-retrieval-lab](https://github.com/iremurhan/clip-retrieval-lab): MSc thesis code. Fine-tuning CLIP for image–text retrieval on COCO and Flickr30k.
- [clip-product-image-text-matching](https://github.com/iremurhan/clip-product-image-text-matching): CLIP fine-tuning to detect mismatched product images and titles.
- [svhn-handcrafted-features](https://github.com/iremurhan/svhn-handcrafted-features): classical image features and classifiers on SVHN digits.
- [pan19-authorship-attribution](https://github.com/iremurhan/pan19-authorship-attribution): cross-domain authorship attribution on PAN-19.
- [ngram-language-identification](https://github.com/iremurhan/ngram-language-identification): character n-gram language identification for nine languages.
- [cancer-biomarker-feature-selection](https://github.com/iremurhan/cancer-biomarker-feature-selection): gene selection on microarray data (BSc graduation project).
